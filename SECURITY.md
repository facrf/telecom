# Segurança

O Telecom é destinado a inventário e diagnóstico de redes para as quais o operador possui autorização. As fases de descoberta e scanner não devem ser usadas em redes de terceiros.

Nesta fundação, a aplicação inclui CSP, proteção contra frame, `nosniff`, política de referenciador restrita e erros HTTP estruturados sem stack trace. Não há telemetria e não há armazenamento de credenciais de equipamentos.

Para relatar uma vulnerabilidade, contate o mantenedor do projeto de forma privada. Não publique detalhes exploráveis antes de uma correção estar disponível.
